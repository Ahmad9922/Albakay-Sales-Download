# تحميل Albakay Sales

اختر **نسخة واحدة** وحمّلها على حاسوب الخادم:

| النسخة | متى تختارها | التحميل |
|---|---|---|
| **الكاملة** | الحالة المعتادة: تثبّت SQL Server Express تلقائياً إن لم يكن على الحاسوب | [Albakay-Sales.zip](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales.zip) (نحو 790 MB) |
| **بدون SQL Server** | حاسوب عليه SQL Server مثبت مسبقاً فقط | [Albakay-Sales-without-SQL-Server.zip](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales-without-SQL-Server.zip) (نحو 75 MB) |

إن لم تكن متأكداً، حمّل **النسخة الكاملة**.

## بعد التحميل

1. انقر على الملف بالزر الأيمن ← **استخراج الكل** (Extract All).
2. افتح المجلد المستخرج، واقرأ الملف **«1- اقرأني أولاً»**: فيه خطوات التثبيت كاملة.
3. شغّل **«2- Albakay Sales Server Setup»** على حاسوب الخادم.
4. ثبّت **«3- Albakay Sales.apk»** على الهواتف.

بعد التثبيت أرسل **معرّف الجهاز** الذي يظهر في نهاية التثبيت إلى المطوّر لإصدار مفتاح الترخيص.

الإصدارات السابقة في صفحة [الإصدارات](https://github.com/Ahmad9922/Albakay-Sales-Download/releases).

# Download Albakay Sales

Choose **one edition** and download it on the server computer:

| Edition | When to choose it | Download |
|---|---|---|
| **Full** | The usual case: installs SQL Server Express when the computer does not have it | [Albakay-Sales.zip](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales.zip) (about 790 MB) |
| **Without SQL Server** | Only for a computer that already has SQL Server | [Albakay-Sales-without-SQL-Server.zip](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales-without-SQL-Server.zip) (about 75 MB) |

If you are not sure, download the **full edition**.

## After downloading

1. Right-click the file → **Extract All**.
2. Open the extracted folder and read **"1- Read me first"**: it has the full installation steps.
3. Run **"2- Albakay Sales Server Setup"** on the server computer.
4. Install **"3- Albakay Sales.apk"** on the phones.

After installing, send the **device id** shown at the end of the setup to the developer for the license key.

Earlier versions are on the [releases](https://github.com/Ahmad9922/Albakay-Sales-Download/releases) page.

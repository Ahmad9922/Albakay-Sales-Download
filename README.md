# تحميل Albakay Sales

اختر **نسخة واحدة** وحمّلها على حاسوب الخادم:

| النسخة | متى تختارها | التحميل |
|---|---|---|
| **الكاملة** | الحالة المعتادة: تثبّت SQL Server Express تلقائياً إن لم يكن على الحاسوب | [Albakay-Sales.zip](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales.zip) (نحو 890 MB) |
| **بدون SQL Server** | حاسوب عليه SQL Server مثبت مسبقاً فقط | [Albakay-Sales-without-SQL-Server.zip](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales-without-SQL-Server.zip) (نحو 175 MB) |

إن لم تكن متأكداً، حمّل **النسخة الكاملة**.

## بعد التحميل

1. انقر على الملف بالزر الأيمن ← **استخراج الكل** (Extract All).
2. افتح المجلد المستخرج، واقرأ الملف **«1- اقرأني أولاً»**: فيه خطوات التثبيت كاملة.
3. شغّل **«2- Albakay Sales Server Setup»** على حاسوب الخادم.
4. شغّل **«3- Albakay Sales Desktop Setup»** على كل حاسوب يُعمل عليه.
5. ثبّت **«4- Albakay Sales.apk»** على الهواتف.

بعد التثبيت أرسل **معرّف الجهاز** الذي يظهر في نهاية التثبيت إلى المطوّر لإصدار مفتاح الترخيص.

## تطبيق الهاتف منفرداً

لتثبيت التطبيق على هاتف آخر أو تحديثه، افتح هذا الرابط من متصفح الهاتف نفسه، دون حاجة إلى الحزمة كاملة:

[Albakay-Sales.apk](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales.apk) (نحو 90 MB)

إن طلب الهاتف السماح بالتثبيت من مصادر غير معروفة فاسمح به للمتصفح. التحديث يُثبَّت فوق النسخة الموجودة ولا يمسح بياناتها.

# Download Albakay Sales

Choose **one edition** and download it on the server computer:

| Edition | When to choose it | Download |
|---|---|---|
| **Full** | The usual case: installs SQL Server Express when the computer does not have it | [Albakay-Sales.zip](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales.zip) (about 890 MB) |
| **Without SQL Server** | Only for a computer that already has SQL Server | [Albakay-Sales-without-SQL-Server.zip](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales-without-SQL-Server.zip) (about 175 MB) |

If you are not sure, download the **full edition**.

## After downloading

1. Right-click the file → **Extract All**.
2. Open the extracted folder and read **"1- Read me first"**: it has the full installation steps.
3. Run **"2- Albakay Sales Server Setup"** on the server computer.
4. Run **"3- Albakay Sales Desktop Setup"** on every computer people work on.
5. Install **"4- Albakay Sales.apk"** on the phones.

After installing, send the **device id** shown at the end of the setup to the developer for the license key.

## The phone app on its own

To install the app on another phone, or to update it, open this link in the phone's own browser, without the whole package:

[Albakay-Sales.apk](https://github.com/Ahmad9922/Albakay-Sales-Download/releases/latest/download/Albakay-Sales.apk) (about 90 MB)

If the phone asks to allow installing from unknown sources, allow it for the browser. An update installs over the app already there and keeps its data.

Earlier versions are on the [releases](https://github.com/Ahmad9922/Albakay-Sales-Download/releases) page.
